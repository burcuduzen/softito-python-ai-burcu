# Otel Rezervasyon EDA

Temizleme, gruplama, feature engineering ve görselleştirme. Büyük veri için Hotel Booking Demand kataloğu bulunur.

## Çalıştırma

```bash
cd 03_EDA
python hotel_booking_eda.py
```

Ana veri kaynağı ve indirme bilgisi için kök dizindeki `datasets.yaml` dosyasına bakın. Büyük veri bulunmadığında uygun bölümler tekrarlanabilir demo verisi üretir.
